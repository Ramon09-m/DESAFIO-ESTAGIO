📊 Desafio de Estágio – Análise Quantitativa e Estratégia de Investimento
Este projeto foi desenvolvido como parte de um processo seletivo para estágio, com foco em análise de indicadores financeiros, avaliação de risco e construção de uma estratégia de investimento de longo prazo. Todo o trabalho foi realizado em Python, com exceção da definição da estratégia, que foi elaborada manualmente com base em premissas quantitativas e qualitativas.

🧠 Objetivo
Realizar uma análise comparativa entre diversos indicadores financeiros, construir um ranking de risco com base em métricas quantitativas e simular uma estratégia de alocação de ativos para o período de 2020 a 2024.

🛠️ Tecnologias Utilizadas
Python 3.10+

Pandas para manipulação de dados

NumPy para cálculos estatísticos

Matplotlib / Seaborn para visualizações

Fontes de dados:

Investing.com – ativos financeiros

IBGE – IPCA (inflação)
